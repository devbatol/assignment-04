Module 1: Web & Developer Foundations

  • Assignment 1 -- Explain the Internet: A conceptual breakdown of web infrastructure, defining the internet versus the web, core server-browser roles, HTTP, and an illustrated end-to-end journey diagram.
  • Assignment 2 -- Frontend or Backend?: A structured classification table mapping 18 real-world application features across frontend, backend, and database layers with detailed architectural reasoning.
  • Assignment 3 -- Identify the Client and Server: An analytical scenario breakdown identifying clients, servers, HTTP requests, and responses across six real-world examples, paired with a database-fetching process explanation.
  • Assignment 4 -- URLs, DNS, IP Addresses and Ports: A deep-dive component breakdown dissecting URLs into protocols, subdomains, domains, paths, and query strings, paired with local network terminal exploration.
  • Assignment 5 -- HTTP Methods and Status Codes: A comprehensive HTTP operations guide matching correct request methods to backend actions and interpreting standard response status codes.
  • Assignment 6 -- Developer File Structure: An organized architectural workspace setup mapping directory hierarchies, parent-child path relationships, and core file extension classifications.
  • Compulsory Practical -- Terminal Challenge: A command-line practical executing terminal-only navigation, workspace directory creation, and cleanups without a graphical file manager.
  • Assignment 8 -- Set Up Your Development Workspace: A VS Code configuration exercise demonstrating core editor tools, workspace management, integrated terminal navigation, and the command palette.
  • Assignment 9 -- Inspect a Real Website with DevTools: A live DOM and network inspection task using Chrome DevTools to trace HTTP request headers, methods, status codes, and console logs.
  • Compulsory Final Assessment -- Trace a Web Request: An end-to-end architectural trace mapping a browser request to shop.example.com/products/25 across DNS lookup, HTTP messaging, server execution, and database retrieval.
